# Skill 09 — Software Application Development (WorldSkills)

## Overview
This project is a dedicated webpage for Skill 09: Software Application Development at WorldSkills. The site will present information, resources, and examples related to the Skill 09 competition and curriculum.

## Purpose
- Serve as an informational and educational landing page for Skill 09.
- Showcase sample projects, links to resources, and competition guidelines.

## Deployment
The site will be deployed to Cloudflare using Cloudflare Workers (Workers Sites or Pages backed by Workers). Deployment will target Cloudflare's edge platform to provide low-latency global delivery.

## Technologies (suggested)
- Static site: HTML, CSS, JavaScript
- Optional frameworks/build tools: Vite, Astro, Svelte, React, or plain static assets
- Hosting/deployment: Cloudflare Workers (Workers Sites / Pages + Workers)

## Notes
- Keep the project structure simple and edge-friendly for Cloudflare Workers.
- Use standard CI/CD practices to automate deployment to Cloudflare.
